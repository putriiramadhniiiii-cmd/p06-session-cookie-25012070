## Tujuan

Praktikum ini bertujuan untuk mempelajari penggunaan session dan cookie pada PHP.
Selain itu, praktikum ini juga bertujuan untuk memahami cara menyimpan,
mengambil, dan mengelola data menggunakan session dan cookie.

## Cara Menjalankan

1. Pastikan XAMPP sudah terpasang.
2. Jalankan Apache melalui XAMPP.
3. Simpan folder `pertemuan-06` di dalam folder `htdocs/web1`.
4. Buka Visual Studio Code.
5. Buka folder `pertemuan-06`.
6. Jalankan program PHP melalui browser.
7. Buka alamat:

   `http://localhost/pertemuan-06/`
